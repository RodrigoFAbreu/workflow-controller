## Verify a `claude` build with one command (1.19.0)

**`workflow-controller verify-claude [--force]` checks the build a launch would run.** It runs three live probes
(`boundary`, `retry` and `missing_component`) against that `claude`. The probes use your existing Claude credentials,
copied into a scratch home. They cost up to two short model turns at low effort. The usage budget is not consulted. See
[`verify-claude`](../guide/commands.md#verify-claude).

**A clean pass is recorded.** Only then does the command record the build's SHA-256 digest in
`<runtime root>/verified-claude-builds.json`. The file has mode 0600 and is owner-checked. It is read without following
symlinks and written under a lock. The digest is never written to the settings file. A refusal exits `20`.

**The tester launch uses the list.** The functional-tester launch now admits the built-in verified list (Claude Code
2.1.303) plus the recorded digests. It executes the one resolved real file that it hashed and probed (#114).

**Short temporary folder.** The probes use a short private `wcf-*` `TMPDIR`, so Claude's bridge sockets stay under the
107-byte path limit. A sandbox that cannot start is reported as one inconclusive cause.

## Requirements

Unchanged from 1.18.0 (`bwrap`, `socat`, a kernel that accepts a seccomp filter and a `claude` build that is admitted).
`verify-claude` also needs the credential file in your Claude home.

## Known limitations

- **Claude Code 2.1.304 and later are refused.** Builds 2.1.304, 2.1.308 and 2.1.309 were tried. Each fails with
  `boundary: writable: REFUSED, expected WROTE`, because those builds block writes to allowed folders inside the denied
  clone. This is issue [#129](https://github.com/RodrigoFAbreu/workflow-controller/issues/129) (C10f, planned next).
  Until it ships, no newer build can be verified, and the automatic functional review needs Claude Code 2.1.303.
- **Follow-ups filed:**
  [#132](https://github.com/RodrigoFAbreu/workflow-controller/issues/132) and
  [#133](https://github.com/RodrigoFAbreu/workflow-controller/issues/133).

## Upgrading

Install 1.19.0 as you installed 1.18.0 (see the [update page](../update.md)). Keep Claude Code 2.1.303 for the
automatic functional review until #129 ships.
