# Environment the installed claude needs (Claude Code 2.1.296)

command -v claude     -> /home/rodrigo/.local/bin/claude (symlink)
readlink -f           -> /home/rodrigo/.local/share/claude/versions/2.1.296
file                  -> ELF 64-bit LSB executable, x86-64, dynamically linked, interpreter /lib64/ld-linux-x86-64.so.2
                         (257 MB single binary: no node, no #! line, no package directory)
review.interpreter_dir(binary) reads the first line, finds no '#!', returns None: correct; PATH needs only the system
dirs (+ the binary's dir, harmless).  Either the symlink or the resolved path works (the versioned path changes on every
upgrade; the symlink does not).
Ripgrep               -> embedded (Grep/Glob need no rg on PATH)
git                   -> taken from PATH when cwd is a git repository (gitStatus in the system prompt; run 8)

## The exact environment every real run used (env -i; nothing else), and it worked:
PATH=/home/rodrigo/.local/bin:/usr/local/bin:/usr/bin:/bin
HOME=<home>  TMPDIR=<home>/tmp  CLAUDE_CONFIG_DIR=<home>/.claude
XDG_CONFIG_HOME=<home>/.config  XDG_STATE_HOME=<home>/.local/state  XDG_CACHE_HOME=<home>/.cache
GIT_CEILING_DIRECTORIES=/home/rodrigo/.cache/c14-prestep
LANG=C.UTF-8  LC_ALL=C.UTF-8
DISABLE_AUTOUPDATER=1  CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
run 7 added CLAUDE_CODE_DISABLE_AUTO_MEMORY=1; run 8 added CLAUDE_CODE_DISABLE_AUTO_MEMORY=1 ENABLE_CLAUDEAI_MCP_SERVERS=false.
No USER, SHELL, TERM, LOGNAME, DISPLAY, proxy, CA, ANTHROPIC_* or CLAUDE_CODE_OAUTH_TOKEN variable.

Notes:
- CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1: debug "[Bootstrap] Skipped: Nonessential traffic disabled",
  "[servedCatalog] off (essential_traffic)"; init analytics_disabled=true, product_feedback_disabled=true.
- DISABLE_AUTOUPDATER=1: debug "Plugin autoupdate: skipped (auto-updater disabled)".
- ENABLE_CLAUDEAI_MCP_SERVERS=false: debug "[claudeai-mcp] Disabled via env var"; without it the CLI fetches
  https://api.anthropic.com/v1/mcp_servers even under --strict-mcp-config (run 7), though it exposes none.
- A UNIX socket for message injection listens at $TMPDIR/cc-socks/<pid>.sock during every run ("[uds-messaging]
  Listening: ..."; CLAUDE_CODE_MESSAGING_SOCKET/TOKEN); keep TMPDIR private (0700) to the job.
- Other disable variables named in the binary but not exercised: CLAUDE_CODE_DISABLE_CLAUDE_MDS,
  CLAUDE_CODE_DISABLE_BUNDLED_SKILLS, CLAUDE_CODE_DISABLE_BACKGROUND_TASKS, CLAUDE_CODE_DISABLE_FILE_CHECKPOINTING,
  CLAUDE_CODE_DISABLE_EXPLORE_PLAN_AGENTS, CLAUDE_CODE_SIMPLE (set by --bare), CLAUDE_CODE_SAFE_MODE (set by --safe-mode).
